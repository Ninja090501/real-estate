# Real Estate Website (Responsive Landing Page)

A modern and responsive real estate website built with **HTML, CSS, and JavaScript**. This project showcases property listings with clean design, mobile-first responsiveness, and user-friendly navigation. Perfect for real estate agencies, agents, or property listing platforms.

## Features

- Responsive design optimized for mobile, tablet, and desktop
- Property listing cards with images, prices, and brief details
- Hero section with background image or slider
- Call-to-action buttons (Contact Agent, View Details)
- Navigation bar and footer
- Scroll animations (optional)
- Lightweight and fast-loading

## Technologies Used

- **HTML5** – Semantic layout and structure
- **CSS3** – Flexbox/Grid for layout and responsiveness
- **JavaScript** – Interactive elements (like image sliders or toggle menus)
